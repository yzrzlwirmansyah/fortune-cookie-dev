One original line of fortune-cookie wisdom for a software developer: "Legacy code is not a mess; it is a decision that outlived its meeting." It is a single short balanced sentence, true about every developer's day — the code you inherit is never just a mess, it is a choice someone made in a meeting nobody remembers, still running in production long after the meeting ended — and its quiet twist is that the most forgettable part of the job (the meeting) is outlived by the most durable part (the decision).

## Run it

```sh
MAKEFUN_OUTPUT_DIR=./out python3 main.py
```
